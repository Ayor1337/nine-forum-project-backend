## 验证命令

```powershell
./mvnw.cmd clean test
./mvnw.cmd dependency:tree
git status --short
```

扫描工具命令将在基线阶段按本机实际可用工具确定，并原样记录在 `research/audit-matrix.md`，避免把未执行的工具写成已验证结果。

## 停止与回退点

- 任何动态测试超出 localhost、要求爆破、产生批量写入或导致服务不稳定：停止动态测试。
- 发现数据库状态发生变化：停止审计并报告，不自行恢复。
- 依赖扫描无法访问漏洞数据源：标记为受限，不能下“无已知漏洞”结论。
